# KSSU-Practice v3.1

- 星のカービィウルトラスーパーデラックスのRTA練習用改造コード
- 日本版ROMでのみ動作可能
- 実機でのテストは、New3DSでnds-bootstrap v2.2.2で行った

## 導入方法

1. Releasesから`usrcheat.dat`をダウンロード
2. SDカードに配置する
   - CFWを導入済みの3DSの場合、NDSForwarderを使うなら`sd:/_nds/ntr-forwarder/usrcheat.dat`に、TWiLight Menu++を使うなら`sd:/_nds/TWiLightMenu/extras/usrcheat.dat`に配置
     - ちなみにFTPDを使って無線でファイルのやりとりができる

## 仕様

- **ポーズ中**:
  - **十字+L**:
    - 十字キーの方向（ニュートラル含む9通り）でセーブスロットを指定してQS
      - セーブスロットはゲームモード(はるかぜとともに、ダイナブレイド、etc)ごとにある
    - ほおばり状態でQSした場合、吸い込みをしたときそれをほおばるようになる
  - **十字+X**:
    - QSを解除
  - **十字+R**:
    - 自動ロードのモードを設定
      - ニュートラル: なし
      - 左: 全てのフロア遷移時に強制ループ
      - 左上: ステージクリア時/格闘王系の戦闘開始時に現在選択されているスロットでQL
      - 上: ステージクリア時/格闘王系の戦闘開始時に現在選択されていないスロットからランダムに1つ選んでQL
  - **Y+左右**:
    - 格闘王系のモードでボスを変更
- **プレイ中**:
  - **L**:
    - 前回QS/QLしたスロットでQLする
  - **R+十字+L**:
    - 十字キーで指定したセーブスロットでQL
  - **R+X+十字+L**:
    - 十字で能力を指定して、現在のフロアに遷移した状態をロード（ニュートラル: ジェット、上: ウィング、右上: ホイール、右: ストーン、右下: パラソル、下: ハンマー、左下: ファイア、左: すっぴん、左上: ニンジャ）
  - **R+Y+L**:
    - 初期座標を現在の座標にして、現在のフロアに遷移した状態をロード
  - **Y+L**:
    - 直前のフロアに遷移した状態をロード
  - **Y+R**:
    - 現在のフロアに遷移した状態をロード
  - **R+START**:
    - 通常ポーズが制限されている場面でも、強制的にポーズ
- **数値表示**:
  - 下画面に4桁の数値が4つ表示され、フロア遷移時のタイムを一番左に、フロアごとのタイムを右3つに表示する
  - ミックスをしたときに4Fのどのタイミングだったかを一番右に「1000→0100→0010→0001」という形で表示する(最初の能力の1F目では機能しない)
- **QSQLされる情報**:
  - フロア、座標、開始時の状態(ワープスターに乗っているかやゴールゲーム中かなど)
  - むてきキャンディ/メタクイックの残り時間
  - コピー能力、ヘルパー、ウィリーライダーか
  - 銀河にねがいをのコピーのもとデラックス取得状況と選択位置
  - 格闘王系でのボス
  - 曲を最初からにするか
- **他の仕様**:
  - メタナイトの逆襲のタイマーを減らなくする
  - むてきキャンディや1UPやマキシムトマトはフロア遷移で復活する
  - ダイナブレイドのスイッチはフロア遷移で復活するが、マップでおためし部屋は常に開放される
  - QL時にはタイマーのリセット、HP全回復、残機99、メタナイトでゴーのPt最大、洞窟大作戦の宝箱とボスの復活が行われる
  - 格闘王系のモードでは休憩部屋ではなく戦闘がQLされ、1戦目になる
